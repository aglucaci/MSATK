# Format Fixtures

This directory contains tiny synthetic fixtures for every MSATK-supported input family.

| Format | Fixture |
|---|---|
| FASTA | `tiny.aligned.fasta` |
| aligned FASTA | `tiny.aligned.fasta` |
| A3M | `tiny.a3m` |
| PHYLIP | `tiny.phy` |
| relaxed PHYLIP | `tiny_relaxed.phylip` |
| CLUSTAL | `tiny.clustal` |
| Stockholm | `tiny.stockholm` |
| NEXUS | `tiny.nexus` |
| MAF | `tiny.maf` |
| SAM | `tiny.sam` |
| BAM | `tiny.bam` |
| CRAM | generated with `create_binary_alignment_fixtures.py` |

`tiny.bam` is generated by `create_tiny_bam.py`, which has no external dependencies.

`tiny.cram` is generated by `create_binary_alignment_fixtures.py` when `pysam`/HTSlib is available. CRAM is reference-based, so the fixture uses `reference.fasta`.
