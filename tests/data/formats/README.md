# Format Fixtures

Tiny synthetic fixtures for every format that the capability registry
(`msatk.alignments.registry`) declares as stable or beta. A test loads each one and checks it
produces the declared data model. Expected values in `tests/unit/test_alignment_types.py`
are calculated by hand from these files.

| Format | Data model | Fixture(s) |
|---|---|---|
| FASTA (aligned) | sequence | `tiny.aligned.fasta` |
| PHYLIP / relaxed PHYLIP | sequence | `tiny.phy`, `tiny_relaxed.phylip` |
| CLUSTAL | sequence | `tiny.clustal` |
| NEXUS (+ charsets) | sequence | `tiny.nexus`, `partitioned.nexus` |
| Stockholm (+ SS_cons, RF) | sequence | `tiny.stockholm`, `rna_structure.sto` |
| A3M / A2M | sequence (profile states) | `tiny.a3m`, `tiny.a2m` |
| MSF, MEGA, SELEX, MASE | sequence | `tiny.msf`, `tiny.meg`, `tiny.slx`, `tiny.mase` |
| EMBOSS needle | sequence (pairwise) | `tiny.needle` |
| MAF | block | `tiny.maf`, `blocks.maf` (3 genomes, inverted block) |
| XMFA, AXT | block | `tiny.xmfa`, `tiny.axt` |
| SAM | read | `tiny.sam`, `reads.sam` (pairs, clipping, indels, splicing, duplicate, secondary, unmapped) |
| BAM | read | `tiny.bam` (needs pysam) |
| PAF, PSL, BLAST tabular, GAF | mapping | `tiny.paf`, `tiny.psl`, `tiny.m8`, `tiny.gaf` |
| GFA 1 / rGFA | graph | `tiny.gfa` (2 paths + 1 walk, rGFA ranks) |
| HMMER3, HHM | profile_model | `tiny.hmm`, `tiny.hhm` |

`tiny.bam` is generated by `create_tiny_bam.py`, which has no external dependencies. CRAM is
reference-based, so `create_binary_alignment_fixtures.py` can generate `tiny.cram` from
`reference.fasta` when `pysam`/HTSlib is available. CRAM is marked *experimental* in the
registry until a CRAM fixture is tested in CI.
